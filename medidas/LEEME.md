# Medidas para la memoria

| Fichero | Cómo se obtiene | Para qué pregunta |
|---|---|---|
| `recv_primaria.csv` | `python primaria.py --modo bytes --registro medidas/recv_primaria.csv` (1 minuto) | 1 |
| `recv_tiempo_real.csv` | `python tiempo_real.py --modo bytes --registro medidas/recv_tiempo_real.csv` (1 minuto) | 1, 4 |
| `aula_*.txt` | Salidas copiadas de cada hito | Memoria, apartado de pruebas |
